2. Configure

3. First repository

bash
mkdir -p ~/lab/git-demo && cd ~/lab/git-demo && git init
echo "# demo" > README.md
git status; git add README.md; git commit -m "docs: add readme"
git log --oneline --graph --all

4. Branch and merge

bash
git switch -c feature/login
echo login > login.txt && git add . && git commit -m "feat: login"
git switch main
git merge --no-ff feature/login -m "merge login"
git branch -d feature/login
git log --oneline --graph

5. Create and resolve a conflict

bash
echo one > c.txt && git add c.txt && git commit -qm base
git switch -c a; echo A > c.txt; git commit -qam a
git switch main; git switch -c b; echo B > c.txt; git commit -qam b
git merge a            # CONFLICT is expected
git status --short; cat c.txt
echo resolved > c.txt; git add c.txt; git commit -qm resolve

6. Undo safely

SituationCommandRewrites history?
Unstage a filegit restore --staged fNo
Discard working changesgit restore fNo (changes are lost)
Undo a pushed commitgit revert <sha>No
Amend last local commitgit commit --amendYes
Recover lost commitsgit reflog, then git switch -c rescue <sha>No
Rule
Never force-push a shared branch. If unavoidable, use git push --force-with-lease.

7. Remotes, stash, tags, rebase

bash
git init --bare ~/lab/remote.git
git remote add origin ~/lab/remote.git
git push -u origin main
git clone ~/lab/remote.git ~/lab/clone2
echo wip >> README.md; git stash push -m wip; git stash list; git stash pop
git tag -a v1.0.0 -m "first release" && git push origin v1.0.0
git switch -c topic; git rebase main
