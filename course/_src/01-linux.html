3. Users, groups, sudo

bash
adduser --disabled-password --gecos "" devops
usermod -aG sudo devops
echo "devops ALL=(ALL) NOPASSWD:ALL" > /etc/sudoers.d/devops
chmod 440 /etc/sudoers.d/devops && visudo -c
getent passwd devops; id devops
Safety
Edit sudoers only through visudo or a file under /etc/sudoers.d, then validate with visudo -c. A syntax error can remove your sudo access.

4. Key-based remote login and hardening

bash
install -d -m 700 -o devops -g devops /home/devops/.ssh
ssh-keygen -t ed25519 -f /root/lab_key -N "" -C lab
cat /root/lab_key.pub >> /home/devops/.ssh/authorized_keys
chown devops:devops /home/devops/.ssh/authorized_keys; chmod 600 /home/devops/.ssh/authorized_keys
# open a SECOND terminal and confirm key login works before the next step
printf 'PasswordAuthentication no\nPermitRootLogin prohibit-password\n' > /etc/ssh/sshd_config.d/99-hardening.conf
sshd -t && systemctl reload ssh

6. Processes and systemd

bash
ps aux --sort=-%mem | head -5
systemctl status ssh --no-pager
systemctl list-units --failed
journalctl -u ssh -n 20 --no-pager
cat > /etc/systemd/system/hello.service <<'EOT'
[Unit]
Description=Hello demo
[Service]
ExecStart=/bin/bash -c 'while true; do echo hello; sleep 5; done'
Restart=always
[Install]
WantedBy=multi-user.target
EOT
systemctl daemon-reload && systemctl enable --now hello
journalctl -u hello -n 3 --no-pager; systemctl disable --now hello

7. Disks and filesystems

bash
lsblk -f; df -hT; findmnt /
# practise on a loop file, never on a real disk
fallocate -l 200M /root/disk.img
mkfs.ext4 -q /root/disk.img
mkdir -p /mnt/lab && mount -o loop /root/disk.img /mnt/lab
df -h /mnt/lab; umount /mnt/lab

8. Networking and firewall

bash
ip -br a; ip r; ss -tulpn
dig +short example.com; curl -sI https://example.com | head -1
ufw allow OpenSSH && ufw allow 80,443/tcp
ufw allow 6443/tcp; ufw allow 30000:32767/tcp   # Kubernetes API and NodePorts (lab only)
ufw --force enable && ufw status verbose
Order matters
Allow remote login before enabling ufw, or you will cut your own session. On cloud servers also check the provider security group.

10. Kernel settings Kubernetes needs

bash
swapoff -a && sed -i '/ swap / s/^/#/' /etc/fstab
printf 'overlay\nbr_netfilter\n' > /etc/modules-load.d/k8s.conf
modprobe overlay; modprobe br_netfilter
printf 'net.bridge.bridge-nf-call-iptables=1\nnet.bridge.bridge-nf-call-ip6tables=1\nnet.ipv4.ip_forward=1\n' > /etc/sysctl.d/k8s.conf
sysctl --system | tail -3; sysctl net.ipv4.ip_forward
Checkpoint
You can log in as devops with a key, systemctl list-units --failed is empty, and sysctl net.ipv4.ip_forward returns 1.
