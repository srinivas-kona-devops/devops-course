2. CLI install and safe authentication

bash
cd /tmp && curl -s "https://awscli.amazonaws.com/awscli-exe-linux-$(uname -m).zip" -o awscliv2.zip
unzip -q awscliv2.zip && ./aws/install --update
aws --version
aws configure sso --profile lab         # preferred: short-lived credentials through IAM Identity Center
aws sso login --profile lab
export AWS_PROFILE=lab AWS_REGION=ap-south-1
aws sts get-caller-identity
# alternative for a sandbox only: aws configure   (access key pair of an IAM user, never root)
Output controls
--output table|json|text, --query 'Reservations[].Instances[].InstanceId' (JMESPath), --no-cli-pager, --dry-run on many EC2 calls.

3. IAM: identities and least privilege

ConceptMeaning
UserLong-lived identity. Prefer Identity Center instead
RoleTemporary credentials assumed by people, EC2, pods, CI
PolicyJSON that allows or denies actions on resources; explicit deny wins
Instance profile / IRSA / Pod IdentityHow compute gets a role without stored keys
bash
cat > /tmp/trust.json <<'EOT'
{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"Service":"ec2.amazonaws.com"},"Action":"sts:AssumeRole"}]}
EOT
cat > /tmp/s3ro.json <<'EOT'
{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Action":["s3:GetObject","s3:ListBucket"],"Resource":["arn:aws:s3:::BUCKET","arn:aws:s3:::BUCKET/*"]}]}
EOT
aws iam create-role --role-name lab-ec2 --assume-role-policy-document file:///tmp/trust.json
aws iam put-role-policy --role-name lab-ec2 --policy-name s3ro --policy-document file:///tmp/s3ro.json
aws iam simulate-principal-policy --policy-source-arn $(aws iam get-role --role-name lab-ec2 --query Role.Arn --output text) --action-names s3:GetObject s3:DeleteObject --resource-arns arn:aws:s3:::BUCKET/x --query 'EvaluationResults[].[EvalActionName,EvalDecision]' --output table
aws iam delete-role-policy --role-name lab-ec2 --policy-name s3ro; aws iam delete-role --role-name lab-ec2

5. Compute: EC2

bash
AMI=$(aws ssm get-parameter --name /aws/service/canonical/ubuntu/server/24.04/stable/current/amd64/hvm/ebs-gp3/ami-id --query Parameter.Value --output text)
aws ec2 create-key-pair --key-name lab --query KeyMaterial --output text > ~/.ssh/lab.pem && chmod 600 ~/.ssh/lab.pem
aws ec2 run-instances --image-id $AMI --instance-type t3.micro --key-name lab --metadata-options HttpTokens=required \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=lab}]' --query 'Instances[0].InstanceId' --output text
aws ec2 describe-instances --filters Name=tag:Name,Values=lab --query 'Reservations[].Instances[].[InstanceId,State.Name,PublicIpAddress]' --output table
aws ec2 terminate-instances --instance-ids i-REPLACE_ME

Related: Auto Scaling Groups with Launch Templates (self-healing fleets), Application Load Balancer (HTTP routing, health checks), Systems Manager Session Manager (shell access with no open port 22).

6. Storage and databases

bash
B=lab-$RANDOM-$(date +%s)
aws s3 mb s3://$B --region $AWS_REGION

aws s3api put-public-access-block --bucket $B --public-access-block-configuration BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
echo hi > /tmp/f.txt && aws s3 cp /tmp/f.txt s3://$B/ && aws s3 ls s3://$B

7. Containers: ECR and EKS

bash
ACCT=$(aws sts get-caller-identity --query Account --output text)
aws ecr create-repository --repository-name hello --image-scanning-configuration scanOnPush=true
aws ecr get-login-password | docker login --username AWS --password-stdin $ACCT.dkr.ecr.$AWS_REGION.amazonaws.com
docker tag hello:1.0 $ACCT.dkr.ecr.$AWS_REGION.amazonaws.com/hello:1.0 && docker push $ACCT.dkr.ecr.$AWS_REGION.amazonaws.com/hello:1.0

# EKS with eksctl (about 15-20 minutes; billable control plane and nodes)
curl -sL "https://github.com/eksctl-io/eksctl/releases/latest/download/eksctl_Linux_amd64.tar.gz" | tar xz -C /usr/local/bin
eksctl create cluster --name lab --region $AWS_REGION --nodes 2 --node-type t3.medium --managed
aws eks update-kubeconfig --name lab --region $AWS_REGION
kubectl get nodes
eksctl delete cluster --name lab --region $AWS_REGION    # always clean up
Production pattern
Terraform builds VPC and EKS; the AWS Load Balancer Controller turns Ingress/Service objects into ALBs/NLBs; IRSA or EKS Pod Identity gives pods IAM roles; Karpenter or Cluster Autoscaler adds nodes; External Secrets pulls from Secrets Manager.
